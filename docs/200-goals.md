**Purpose.** Make the desired end state measurable and explicit.

## Draft — Personal Portfolio Site

- **Objective (Phase 0):** a working static portfolio site — hero, about, projects, and contact — viewable in a browser. Measurable: `index.html` loads without errors; sections render; links work. [FACT]
- **Success criteria:** page renders at `http://localhost:8088` via `python3 -m http.server 8088`; no broken internal links; no console errors. [FACT]
- **Non-goals (Phase 0):** no backend, CMS, auth, analytics, build tooling, or external frameworks. [FACT]
- **Definition of done (Phase 0):** Sajan approves content and the site renders locally; Git repo initialized. [FACT]
